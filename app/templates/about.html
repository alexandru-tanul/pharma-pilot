About This System

About Pharma Pilot

An AI-powered pharmaceutical research assistant that translates natural-language questions into SQL queries across three major biomedical databases.

How It Works

1

You ask a question in plain language

For example: "What kinase inhibitors are being tested in ovarian cancer clinical trials?"

2

The AI plans which databases to query

An LLM analyses your question and decides which of the three biomedical databases contain relevant data.

3

SQL queries are generated and executed

The system translates your intent into read-only SQL SELECT queries. If a query fails, the system self-corrects and retries with improved SQL.

4

Results are synthesised into a research answer

The AI combines results from multiple queries into a structured answer with tables, insights, and source attribution.

Data Sources

ClinicalTrials.gov

The world's largest registry of clinical studies. Sourced from the AACT (Aggregate Analysis of ClinicalTrials.gov) dataset.

Records~580,000 studies
IncludesPhases, outcomes, arms

DrugCentral

Comprehensive drug information resource with regulatory, pharmacological, and safety data.

Records~4,500 active ingredients
IncludesTargets, ATC, FAERS

Pharos (NIH TCRD)

Target Central Resource Database from the Illuminating the Druggable Genome programme.

Records~20,000 protein targets
IncludesTdark/Tbio/Tchem/Tclin

Technology Stack

Backend

  • ▸ Python 3.13 + FastAPI
  • ▸ DuckDB (analytical SQL engine)
  • ▸ PostgreSQL 17 (chat persistence)
  • ▸ LiteLLM (LLM gateway)
  • ▸ TortoiseORM + Aerich

Frontend

  • ▸ Jinja2 (server-rendered templates)
  • ▸ HTMX 2.x + Idiomorph
  • ▸ Tailwind CSS (CDN)
  • ▸ Server-Sent Events (real-time)
  • ▸ Docker (multi-stage build)

Limitations

  • ⚠ Data freshness. The biomedical data is loaded from static Parquet files. It reflects a point-in-time snapshot and may not include the most recent clinical trials or drug approvals.
  • ⚠ SQL generation accuracy. The AI may occasionally generate incorrect SQL queries. The system self-corrects up to 3 times, but some complex questions may still produce incomplete results.
  • ⚠ Not a substitute for professional research. This tool is designed to assist researchers in exploratory analysis. Results should be validated against primary sources before use in clinical or regulatory decisions.
